Who we are

EnglishCraft is an English-teaching service for children, run by an individual teacher in Israel. "We" means EnglishCraft. Contact: jordangoren1234@gmail.com.

What we collect, and why

Sign-in (Microsoft account)

The EnglishCraft app signs in with Microsoft so the child can play Minecraft: Java Edition, which they must own. Sign-in happens on Microsoft's own pages; we never see or store the password. The app keeps a sign-in token on the child's computer so they don't have to log in every time. Our server receives the Minecraft username and account ID (UUID), like any Minecraft server.

Learning progress

Our server stores the child's lesson progress: steps completed, words learned, answers to exercises, and per-skill accuracy (listening, reading, writing, speaking). The class teacher sees this to help the child. It is kept on our server while the child is enrolled.

Spoken answers

Some exercises ask the child to say a word or sentence out loud. When the child presses the talk key during a speaking exercise, the EnglishCraft mod records a short answer and our server sends it to OpenRouter, which routes the request to a Google Gemini model for transcription. If a request is slow, the server may send a second copy. We do not save the audio file on our server. The transcript is shown to the child and may be shown to the teacher and stored with learning progress. Our server asks OpenRouter to route these requests only to providers with a zero-data-retention policy that do not use the data for training. OpenRouter and the model provider handle the recording under that setting and their own privacy and data policies. Other players do not hear the recording. Parents must explicitly opt in before a child uses voice exercises; a teacher or typing-based alternative is available.

Typed answers and chat

What the child types as an answer is checked by the server and shown to the teacher. Children's chat is limited to the class and visible to the teacher.

Technical data

Our server keeps standard logs (connection times, IP address, errors) to keep the service working and safe. Archived server logs older than 30 days are removed when the server starts.

Who we share it with

  • Microsoft / Mojang - for sign-in, as required by Minecraft.
  • OpenRouter and Google - only the short spoken answers, for transcription.
  • Our server host, which stores the data on our behalf.

We never sell data, show ads, or share it for marketing.

Children

EnglishCraft is made for children and is used with a parent's consent, in classes led by a teacher. Voice exercises require a separate, explicit parental choice before the child uses them. Parents can ask what we hold about their child, ask us to correct it, or ask us to delete it - email us and we'll do it within 30 days. We keep the 10 most recent server backups, including learning progress; the time they cover depends on how often backups run.

Security

Data is stored on a private server that only we can access, and the game server only lets in approved players.

Changes

If we change this policy we'll update the date above and tell parents about important changes.

EnglishCraft is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.
